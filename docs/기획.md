- **결정 사항**
    - **기능**
        - **핵심 기능:** 내 주변 궁금해하는 건물 시세를 표시 (P0)
        - **대상**: 아파트(P0), 오피스텔, 원룸 (상가류 제외)
        - **주 사용 시나리오**
            - 정차 중 (P0)
                - **케이스**: 신호 대기, 잠깐 갓길 주차
                - **방안**: 디스플레이 활용
            - 주행 중 (P1)
                - **케이스**: 운전 중 궁금한 건물이 생기는 경우
                - **방안**: 자체 제공 AI 기반
        - **주기능**
            - 내 위치 주변 매물들을 사진, 리스트 제공 (P0)
                - **케이스**: 요청 시
                - 내 주변: x km 근방
            - 관심 있어 할만한 매물을 알아서 노티주기 (P1)
                - 온보딩 화면 추가 필요 → 시작 화면 조사
                - 세팅을 안하면 아예 안나오게..
            - 길 안내 기능 (자체 기능 제공) (P1)
                - 실시간
                - 저장 목록 기반
            - 저장 기능 (P0)
                - 저장한 건물들 조회
                    - 맵(약도) 뷰와 함께 보여주는 방안 (P1)
                        - 네이버 지도와 다른 View 제공 (e.g. 입체 3D 모델링, 위성지도)
                        - 제공 환경: 1:2
                        - [기본 지도 or 주행뷰] - [ 리스트 - 지도 ?]
                - Sorting, Filter(내 위치 기반) 기능 (P1)
                    - Filter도 AI로 조정가능하게 (P2)
