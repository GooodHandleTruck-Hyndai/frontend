# 집픽 화면 웹 목업 (피그마용)

앱 코드의 색·글자·간격·아이콘·문구를 그대로 옮긴 정적 HTML이에요. 화면 11개(S-01~S-10, S-03은 넓은 창 포함)가 한 페이지에 프레임으로 나란히 있어요. 단지 이름과 가격은 목업 데이터(`assets/mock`)예요.

## 피그마로 가져오기
1. 이 폴더째로 받아서 `index.html`을 크롬으로 열어요. `fonts` 폴더가 같은 곳에 있어야 글꼴이 맞게 보여요.
2. 크롬 확장 프로그램 **html.to.design**으로 지금 페이지를 캡처해요.
3. 피그마에서 html.to.design 플러그인을 열고 캡처한 파일을 가져와요.
4. 글자를 고치려면 피그마를 쓰는 PC에 `fonts/asta_sans.ttf`를 설치해요.

## 다시 만들기
앱 화면 코드를 바꾼 뒤 목업도 맞추려면:
`python3 gen.py <frontend 폴더> <출력 폴더>`
